# Self-Hosted Runner Provisioning

This document describes how to provision the `adorsys-gis-runner` (or any self-hosted runner) with the tools required by the quality pipeline.

## Overview

The quality pipeline requires:
- **Node.js tools** (ESLint, TypeScript, Prettier): Installed via `pnpm` in CI
- **System binaries** (Semgrep, Hadolint, Actionlint, jscpd, reviewdog, jq): Pre-installed on runner
- **No runtime downloads**: Tools must be pre-cached; no `curl`, `npm install`, or Docker pulls during workflow execution

## Runner Provisioning Checklist

### Prerequisites

- [ ] Runner OS: Linux (Ubuntu 20.04 LTS or later recommended)
- [ ] Runner has sudo access (for installation)
- [ ] Network access to GitHub (for receiving jobs)
- [ ] Local disk space: ~2 GB for tools and caches

### Installation Steps

#### 1. Node.js & pnpm

Node.js is typically already installed on CI runners. Verify and install if needed:

```bash
# Check version (should be 22.x or later for this project)
node --version
pnpm --version

# Install if missing (Ubuntu example)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
npm install -g pnpm@11.5.2
```

#### 2. Semgrep

```bash
# Version: 1.45.0 (update .ci/quality/.tool-versions if upgrading)
curl -fsSL https://github.com/semgrep/semgrep/releases/download/v1.45.0/semgrep-v1.45.0-linux \
  -o /tmp/semgrep
sudo install -m 755 /tmp/semgrep /usr/local/bin/semgrep
semgrep --version  # Verify
```

#### 3. Hadolint

```bash
# Version: 2.12.0 (update .ci/quality/.tool-versions if upgrading)
curl -fsSL https://github.com/hadolint/hadolint/releases/download/v2.12.0/hadolint-Linux-x86_64 \
  -o /tmp/hadolint
sudo install -m 755 /tmp/hadolint /usr/local/bin/hadolint
hadolint --version  # Verify
```

#### 4. Actionlint

```bash
# Version: 1.7.1 (update .ci/quality/.tool-versions if upgrading)
curl -fsSL https://github.com/rhysd/actionlint/releases/download/v1.7.1/actionlint-1.7.1-linux-amd64.tar.gz \
  -o /tmp/actionlint.tar.gz
sudo tar xzf /tmp/actionlint.tar.gz -C /usr/local/bin/
sudo chmod +x /usr/local/bin/actionlint
actionlint -version  # Verify
```

#### 5. jscpd

```bash
# Version: 4.0.5 (update .ci/quality/.tool-versions if upgrading)
npm install -g jscpd@4.0.5
jscpd --version  # Verify
```

#### 6. reviewdog

```bash
# Version: 0.20.0 (update .ci/quality/.tool-versions if upgrading)
curl -fsSL https://github.com/reviewdog/reviewdog/releases/download/v0.20.0/reviewdog_linux_amd64 \
  -o /tmp/reviewdog
sudo install -m 755 /tmp/reviewdog /usr/local/bin/reviewdog
reviewdog -version  # Verify
```

#### 7. jq

```bash
# Version: 1.7.1 (update .ci/quality/.tool-versions if upgrading)
curl -fsSL https://github.com/jqlang/jq/releases/download/jq-1.7.1/jq-linux-amd64 \
  -o /tmp/jq
sudo install -m 755 /tmp/jq /usr/local/bin/jq

```

### Complete Provisioning Script

For automated provisioning, save this as `provision-quality-runner.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "Provisioning adorsys-gis-runner for quality pipeline..."

# Install Node.js tools (if not already present)
if ! command -v node &> /dev/null; then
  echo "Installing Node.js..."
  curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
  sudo apt-get install -y nodejs
fi

if ! command -v pnpm &> /dev/null; then
  echo "Installing pnpm..."
  npm install -g pnpm@11.5.2
fi

# Install Semgrep
if ! command -v semgrep &> /dev/null; then
  echo "Installing Semgrep 1.45.0..."
  curl -fsSL https://github.com/semgrep/semgrep/releases/download/v1.45.0/semgrep-v1.45.0-linux \
    -o /tmp/semgrep && sudo install -m 755 /tmp/semgrep /usr/local/bin/semgrep
fi

# Install Hadolint
if ! command -v hadolint &> /dev/null; then
  echo "Installing Hadolint 2.12.0..."
  curl -fsSL https://github.com/hadolint/hadolint/releases/download/v2.12.0/hadolint-Linux-x86_64 \
    -o /tmp/hadolint && sudo install -m 755 /tmp/hadolint /usr/local/bin/hadolint
fi

# Install Actionlint
if ! command -v actionlint &> /dev/null; then
  echo "Installing Actionlint 1.7.1..."
  curl -fsSL https://github.com/rhysd/actionlint/releases/download/v1.7.1/actionlint-1.7.1-linux-amd64.tar.gz \
    -o /tmp/actionlint.tar.gz && sudo tar xzf /tmp/actionlint.tar.gz -C /usr/local/bin/ && \
    sudo chmod +x /usr/local/bin/actionlint
fi

# Install jscpd
if ! command -v jscpd &> /dev/null; then
  echo "Installing jscpd 4.0.5..."
  npm install -g jscpd@4.0.5
fi

# Install reviewdog
if ! command -v reviewdog &> /dev/null; then
  echo "Installing reviewdog 0.20.0..."
  curl -fsSL https://github.com/reviewdog/reviewdog/releases/download/v0.20.0/reviewdog_linux_amd64 \
    -o /tmp/reviewdog && sudo install -m 755 /tmp/reviewdog /usr/local/bin/reviewdog
fi

# Install jq
if ! command -v jq &> /dev/null; then
  echo "Installing jq 1.7.1..."
  curl -fsSL https://github.com/jqlang/jq/releases/download/jq-1.7.1/jq-linux-amd64 \
    -o /tmp/jq && sudo install -m 755 /tmp/jq /usr/local/bin/jq
fi

echo "Verifying installation..."
node --version
pnpm --version
semgrep --version
hadolint --version
actionlint -version
jscpd --version
reviewdog -version
jq --version

echo "✓ Provisioning complete!"
```

Run with:
```bash
bash provision-quality-runner.sh
```

### Verification

After provisioning, run the verification script:

```bash
.ci/quality/run.sh --verify
```

Or manually check each tool:

```bash
node --version      # v22.x
pnpm --version      # 11.5.2
semgrep --version   # 1.45.0
hadolint --version  # 2.12.0
actionlint -version # 1.7.1
jscpd --version     # 4.0.5
reviewdog -version  # 0.20.0
jq --version        # jq-1.7.1
```

## Ansible Playbook (Recommended)

For repeated or multi-runner provisioning, use Ansible:

```yaml
---
- name: Provision adorsys-gis-runner for quality pipeline
  hosts: adorsys-gis-runner
  become: yes
  
  tasks:
    - name: Install Node.js 22
      shell: |
        curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
        apt-get install -y nodejs
      args:
        executable: /bin/bash
    
    - name: Install pnpm
      npm:
        name: pnpm
        version: "11.5.2"
        global: yes
    
    - name: Install Semgrep
      get_url:
        url: https://github.com/semgrep/semgrep/releases/download/v1.45.0/semgrep-v1.45.0-linux
        dest: /usr/local/bin/semgrep
        mode: '0755'
    
    - name: Install Hadolint
      get_url:
        url: https://github.com/hadolint/hadolint/releases/download/v2.12.0/hadolint-Linux-x86_64
        dest: /usr/local/bin/hadolint
        mode: '0755'
    
    - name: Install Actionlint
      unarchive:
        src: https://github.com/rhysd/actionlint/releases/download/v1.7.1/actionlint-1.7.1-linux-amd64.tar.gz
        dest: /usr/local/bin
        remote_src: yes
        mode: '0755'
    
    - name: Install jscpd
      npm:
        name: jscpd
        version: "4.0.5"
        global: yes
    
    - name: Install reviewdog
      get_url:
        url: https://github.com/reviewdog/reviewdog/releases/download/v0.20.0/reviewdog_linux_amd64
        dest: /usr/local/bin/reviewdog
        mode: '0755'
    
    - name: Install jq
      get_url:
        url: https://github.com/jqlang/jq/releases/download/jq-1.7.1/jq-linux-amd64
        dest: /usr/local/bin/jq
        mode: '0755'
    
    - name: Verify installation
      shell: |
        set -e
        node --version
        pnpm --version
        semgrep --version
        hadolint --version
        actionlint -version
        jscpd --version
        reviewdog -version
        jq --version
      args:
        executable: /bin/bash
      register: verification
    
    - name: Print verification results
      debug:
        var: verification.stdout_lines
```

## Docker Image (Alternative)

To bake provisioning into a container image:

```dockerfile
FROM ubuntu:22.04

# Install system dependencies
RUN apt-get update && apt-get install -y \
    curl \
    git \
    ca-certificates

# Install Node.js 22
RUN curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && \
    apt-get install -y nodejs

# Install pnpm
RUN npm install -g pnpm@11.5.2

# Install quality pipeline tools
RUN curl -fsSL https://github.com/semgrep/semgrep/releases/download/v1.45.0/semgrep-v1.45.0-linux \
      -o /usr/local/bin/semgrep && chmod +x /usr/local/bin/semgrep && \
    curl -fsSL https://github.com/hadolint/hadolint/releases/download/v2.12.0/hadolint-Linux-x86_64 \
      -o /usr/local/bin/hadolint && chmod +x /usr/local/bin/hadolint && \
    curl -fsSL https://github.com/rhysd/actionlint/releases/download/v1.7.1/actionlint-1.7.1-linux-amd64.tar.gz \
      -o /tmp/actionlint.tar.gz && tar xzf /tmp/actionlint.tar.gz -C /usr/local/bin/ && \
    npm install -g jscpd@4.0.5 reviewdog@0.20.0 && \
    curl -fsSL https://github.com/jqlang/jq/releases/download/jq-1.7.1/jq-linux-amd64 \
      -o /usr/local/bin/jq && chmod +x /usr/local/bin/jq

# Verify
RUN semgrep --version && hadolint --version && actionlint -version && \
    jscpd --version && reviewdog -version && jq --version
```

Build with:
```bash
docker build -t converse-frontends-quality-runner:latest .
```

## Troubleshooting

### Tool not in PATH

If a tool isn't found despite installation:

```bash
which semgrep hadolint actionlint jscpd reviewdog jq
echo $PATH
```

Ensure `/usr/local/bin` is in `$PATH`.

### Version mismatch

If a tool is installed but the wrong version:

```bash
# Check installed version
semgrep --version

# Update if needed (see installation steps above)
curl -fsSL <download-url> -o /usr/local/bin/tool && chmod +x /usr/local/bin/tool
```

### Disk space

Quality scanning can use significant disk space. Monitor:

```bash
df -h
du -sh /usr/local/bin/
du -sh ~/.cache/semgrep/
```

Clear caches if needed (safe):

```bash
rm -rf ~/.cache/semgrep/
npm cache clean --force
```

## Maintenance

### Updating Tools

When updating tool versions:

1. Update `.ci/quality/.tool-versions`
2. Update provisioning script/Ansible/Dockerfile with new version URLs
3. Re-provision runner:
   ```bash
   bash provision-quality-runner.sh
   ```
4. Commit changes to repo

### Pre-Staging Semgrep Rules

If using large or custom Semgrep rule packs, pre-stage them on the runner:

```bash
# Add to provisioning script:
mkdir -p /opt/semgrep-rules
curl -fsSL <rule-pack-url> -o /opt/semgrep-rules/custom-rules.yml

# Then in quality.yml, reference:
semgrep --config /opt/semgrep-rules .ci/rules/semgrep .
```
